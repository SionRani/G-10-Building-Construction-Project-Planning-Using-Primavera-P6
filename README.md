G+10 Building Construction Project Planning Using Primavera P6

About the Project

I developed this project to understand how construction planning and scheduling are carried out for a multi-storey building using Primavera P6.

The project is based on a G+10 building, where I created a construction schedule by breaking the overall work into individual activities, estimating their durations, defining activity relationships, and arranging them in a logical sequence.

Through this project, I got practical exposure to construction project planning and learned how scheduling software helps organize and monitor construction activities.

Project Objectives

Prepare a construction schedule for a G+10 building.

Understand the sequence of different construction activities.

Estimate activity durations.

Create relationships and dependencies between activities.

Develop a Work Breakdown Structure (WBS).

Prepare a project timeline using Primavera P6.

Understand how project progress can be monitored against the baseline schedule.
